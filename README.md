# maevskii.blog

Personal blog and landing page for Artemii Maevskii.

Built with [Jekyll](https://jekyllrb.com/) and the [Minima](https://github.com/jekyll/minima) theme, hosted on GitHub Pages.

## Local development

```bash
bundle install
bundle exec jekyll serve
```

## Structure

- `index.md` — home page (landing)
- `about.md` — experience, products, stack, contacts
- `contributions.md` — open source contributions
- `_config.yml` — site configuration
